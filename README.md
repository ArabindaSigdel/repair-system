# Fix My Ride Admin Panel

## Project Overview

Fix My Ride is a platform that digitizes the automobile workshop process. This admin panel provides administrators with the tools to manage users, workshops, and overall platform operations efficiently.

---

## Features

- **Role-Based Access Control (RBAC):** Secure management of admin privileges.
- **User and Workshop Management:** CRUD operations for users and workshops.
- **Authentication:** Secure login with password hashing and optional OTP-based verification.
- **API Responses:** Standardized response structure across endpoints.
- **Extensible Backend:** Modular code structure with easy scalability.

---

## Tech Stack

- **Node.js**: Runtime environment
- **Express.js**: Web framework
- **MongoDB**: Database
- **Mongoose**: ODM for MongoDB
- **JWT**: Authentication
- **Bcrypt**: Password hashing
- **Twilio**: OTP service (for mobile verification)

---
